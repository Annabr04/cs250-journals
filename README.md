# CS 250 Software Development Lifecycle Journals

Journal entries and reflections for CS 250 at SNHU.

## Entries
- **Journal 3 – Product Tester Role** (November 2026): Reflection on interpreting user stories into test cases for the SNHU Travel project, communication with the Product Owner, and a sample clarification email. The full Word document is available from the assignment submission; key points are summarized below.

### Key Themes from Tester Journal
- Acceptance criteria and the who-what-why format were the most helpful for writing measurable test steps.
- Early clarification with the Product Owner (especially around layout, filters, and mobile scope) prevented testing against the wrong assumptions.
- Revised test cases after the slideshow wireframe showed how Agile supports change when communication is clear.
- Sample email to Product Owner Christy requested specific details on Top Destinations format, search columns/sorting, and mobile feature scope.
